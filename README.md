# Loonie Sense

Canadian personal finance tools — mortgage pre-approval estimator, amortization calculators, and more.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app.

## Tools

- **Mortgage Pre-Approval Estimator** — Calculate how much home you can afford based on Canadian mortgage rules (stress test, GDS/TDS ratios, CMHC insurance)
- Mortgage Amortization Calculator *(coming soon)*
- RRSP vs TFSA Optimizer *(coming soon)*

## Tech Stack

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS v4
